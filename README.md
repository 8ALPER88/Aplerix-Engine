# Aplerix-Engine

Windows işletim sistemi için geliştirilmiş bir otomasyon ve masaüstü özelleştirme aracıdır.

**Önemli Not:** Program şu anda erken geliştirme aşamasındadır (Beta).

## Mevcut Özellikler
* **Masaüstü Özelleştirme:** Bu modül şu an betadadır, stabil çalışmayabilir.
* **Otomasyon Modülü:** Şu an için geliştirme aşamasındadır, dışarıdan yeni otomasyon eklenememektedir. Sistemde aktif olan 2 adet hazır otomasyon bulunmaktadır:
  * Auto tuning açma ve kapama işlemleri
  * Nihai performans modunu aktif etme
